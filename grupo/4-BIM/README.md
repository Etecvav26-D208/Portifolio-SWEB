# 📚 4º Bimestre — Sistemas Web

Repositório destinado às atividades desenvolvidas durante o 4º bimestre do curso.

## 🖨️ Atividade — Grafica_Gest

O **Grafica_Gest** é um sistema web de gestão interna para uma gráfica e papelaria fictícia. O projeto tem como objetivo centralizar informações e facilitar o gerenciamento das operações da empresa.

### ⚙️ Funcionalidades do projeto

- Login e controle de permissões dos funcionários;
- Cadastro e gerenciamento de funcionários e produtos;
- Controle de estoque;
- Registro de vendas;
- Cadastro e acompanhamento de pedidos gráficos;
- Relatórios gerenciais em PDF para encaminhamento à APM;
- Painel administrativo com interface responsiva.
